# Першоджерело — Adriatic New Build Radar

> **Тип документа:** головна інструкція / Source of Truth для Adriatic New Build Radar  
> **Версія:** V3.1  
> **Призначення:** використовувати як основний контракт для Codex, collector pipeline, нормалізації даних, snapshot/history та UI.

ПЕРШОДЖЕРЕЛО V2 — ADRIATIC NEW BUILD RADAR Мета: знайти не просто
найкращу новобудову, а найкращий актив для життя сім’ї + збереження
капіталу + оренди + потенціалу зростання.

============================================================ 0. ГОЛОВНИЙ
ПРИНЦИП ============================================================

Radar працює виключно buyer-side.

Мета: PRICE → LOCATION → QUALITY → FAMILY LIFE → RENTAL → GROWTH →
LIQUIDITY → RISK

Не вибирати “найкрасивіший” об’єкт. Вибирати актив з найкращим
risk-adjusted value.

Кожен об’єкт оцінюється одночасно як: 1. Home 2. Investment 3. Rental
asset 4. Resale asset 5. Family-life asset

Основна модель: PROJECT → UNIT → LISTING → SOURCE OBSERVATION

Один Project може мати багато Units. Один Unit може мати багато Listings
на різних сайтах. Один Listing може змінювати ціну, статус, URL, текст і
фото.

Ніколи не втрачати історію попередніх observations.
